## Building

Requirements:

 - Python 3.13 version;
 - C++20 compatiable compiler;
 - CMake 3.19.3+ version;

Just do this:

> git clone https://github.com/wh1t3lord/zircon.git
> cd zircon
> mkdir build
> cmake ..
